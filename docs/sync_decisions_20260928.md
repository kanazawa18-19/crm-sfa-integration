## 追加依頼：契約・受注後の商品と取引先の関連付け

案件に紐づく商品・サービスそれぞれに、その案件の取引先を追加する。案件名や施設名から推測せず、既存の関連IDで結び付ける。商品の他の取引先は保持し、同じ関連を二重追加しない。契約後に商品・取引先を設定した場合にも追随する。失注・解約・空欄への変更で関連を自動削除しない。削除は既決定のマネージャー二段階承認の対象。

既存の確定ステータスは `施設契約 / 契約 / 契約済 / 導入完了 / 受注（書類回収済み） / 受注・商談完了 / 申込済`。現分類では進行中の `口頭受注` も今回の対象に含むか、本人へ番号式で確認中。

関連全件の読取（Notionのページ分割）、同一商品の同時更新、途中失敗の再開、通常同期での関連伝播を含めて実装・検証する。今回の依頼だけで過去案件全件への一括反映は実行しない。対象と差分を先に調査する。
