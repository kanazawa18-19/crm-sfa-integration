## 通常入口

- NotionのチェーンDBで専用試験1件を通常画面から作成。必須4項目不足で保留した後、画面で入力すると本番通知経由でZoho登録・対応表・シート225行目へ自然配送した。
- シートの専用試験1件は、最初に手動で `new:` キーを入れたため行識別情報がなく保留した。これは通常メニューを使わなかった試験操作の誤り。キーだけを消して通常メニューで再試験した。
- 通常メニューでは実不具合を検出。`getRange(row,1,1,maxColumns)` への開発者メタデータ追加がGoogleに拒否された。[公式Range資料](https://developers.google.com/apps-script/reference/spreadsheet/range#addDeveloperMetadata(String,String)) の行全体指定例に合わせ `getRange(row+":"+row)` へ変更。ローカルと紐づくGASの同じ1行を修正・保存した。
- 修正後の通常メニューでNotion・Zohoが作成され、同じ230行目に「Notion登録済み / 外部登録完了」と表示された。
- 両入口ともメモを通常画面から更新し、Notion・Zoho・シートの名称とメモが一致、元のNotion/Zoho IDとシート行を維持することを実読で確認した。
- 片付けと最終不存在確認は処理中。COQLの自然な時間分割・後続実行の分岐は今回も未観測。容量試験や強制遅延は対象外のまま。
